# 年龄分级问卷答案

按 App Store Connect 当前问卷（Apple 帮助页 "Age ratings values and definitions"，2026-11-12 读）。新分级是 4+ / 9+ / 13+ / 16+ / 18+。

## App 内控制

| 问题 | 答案 | 理由 |
|---|---|---|
| Parental Controls（家长控制） | 无 | |
| Age Assurance（年龄验证） | 无 | 条款要求 18+，但 App 内没有验证机制 |

## 功能（Capabilities）

| 问题 | 答案 | 理由 |
|---|---|---|
| Unrestricted Web Access（不受限的网页访问） | 否 | 用户不能在 App 里随意浏览网页；Pinky 只读取公开页面后给出摘要和来源链接 |
| User-Generated Content（用户生成内容） | 是 | 两人共同对话、照片 |
| Social Media（社交媒体） | 否 | 没有公开动态或陌生人关系 |
| Messaging and Chat（消息与聊天） | 是 | 两人共同对话 |
| Advertising（广告） | 否 | |

## 成熟主题

| 问题 | 答案 |
|---|---|
| Profanity or Crude Humor（粗口） | 无 |
| Horror/Fear Themes（恐怖） | 无 |
| Alcohol, Tobacco, or Drug Use or References（烟酒药物） | 偶尔/轻微（约会计划可能提到喝酒的地方） |

## 医疗或健康

| 问题 | 答案 | 理由 |
|---|---|---|
| Medical or Treatment Information（医疗或治疗信息） | 偶尔/轻微 | 经期记录与预测 |
| Health or Wellness Topics（健康话题） | 是 | 关系与情绪健康 |

## 性与裸露

| 问题 | 答案 | 理由 |
|---|---|---|
| Mature or Suggestive Themes（成熟或暗示性主题） | 偶尔/轻微 | 恋爱关系话题 |
| Sexual Content or Nudity | 无 | |
| Graphic Sexual Content and Nudity | 无 | |

## 暴力 / 机会类

全部"无"（卡通暴力、写实暴力、武器、赌博、模拟赌博、竞赛、开箱）。小游戏（五子棋、象棋、飞行棋等）没有奖品，也没有付费随机物品。

## 结果与建议

- 如实回答后，按 Apple 定义大约落在 **13+**（偶尔的医疗信息和偶尔的烟酒提及都对应 13+）。
- **建议**：在问卷结束页把分级手动提高到 **18+**，和使用条款"仅限 18 岁及以上"一致；Pinky 面向成年人的恋爱关系，提高分级不会影响审核。
- 截图和图标按 2.3.8 只用适合所有年龄的内容（已做到）。
