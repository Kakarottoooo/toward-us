## 三、需要你决定的

### 1. 正式后端放哪里（必须先定，审核员要能打开）

现在你手机连的是这台电脑上的服务器（Tailscale 地址），只有装了 Tailscale 的设备能用，审核员打不开；`render.yaml` 里的 Render 免费实例已经连不上。

| 方案 | 每月大概 | 好处 | 坏处 |
|---|---|---|---|
| **A. Render 付费档 + Render Postgres（推荐）** | 约 $13（`render.yaml` 注释里的估算：starter + 数据库 + 1 GB 盘；以 Render 当时价格为准） | `render.yaml`、Postgres 存储、CI 里的 Postgres 测试都现成，改动最小；自动部署 | 要花钱；要把你们俩的内测数据从 JSON 文件迁过去（或先不迁，内测继续用这台电脑） |
| B. Fly.io（和人脉一样） | 约 $5–15 + 数据库 | 你已经熟悉运维 | Pinky 没有 Fly 配置，要新写；Postgres 要另找（Fly 或 Neon） |
| C. 这台电脑 + Tailscale Funnel 公开 | $0 | 不花钱、数据不用迁 | 电脑关机、重启、断网 App 就挂，审核期间挂了直接被拒；家里电脑暴露到公网；不建议正式用户用 |

**推荐 A**：Linus 会说"用已经被测试覆盖的那条路"——Postgres 存储有 CI 真库测试，Render 蓝图现成；钱只在提交审核前一周开始花。内测（你们俩）可以先继续用这台电脑，正式用户走 Render，两边互不影响。定了之后要做的：买/指定域名 → Render 上填环境变量（含 `PINKY_SUPPORT_EMAIL`、`PINKY_OPERATOR`、AI 密钥）→ 用 `TOWARD_US_APP_URL=https://<域名> npm run sync:release` 打正式包。

> 注意 AI 费用：正式后端要用 API（OpenAI 语音、Anthropic 文字），这部分按量付费，和"先不花钱"冲突；每天额度在 `server/ai-budget.mjs`。这一点请和后端一起定。

### 2. 首版收不收费（内购）

| 方案 | 好处 | 坏处 |
|---|---|---|
| **A. 首版免费、不带内购（推荐）** | 审核项最少（不用审商品、不用合并 #111），最快过审；先看真实用量再定价 | 首版没有收入；App 里会员页按钮是灰的（会写"付款功能还在准备"） |
| B. 首版就带会员订阅 + 装扮（$9.99/月、$59.99/年、装扮 $1.99） | 一上线就能收钱 | 要等账号建商品、合并 #111、审核员要测购买和恢复购买，被拒概率更高 |

**推荐 A**：Paul Graham 会说先让人用起来，收费是第二版的事。选 A 时，建议顺手在 iPhone 里把会员入口整个藏起来（一个小改动，告诉我就做），避免审核员看到灰按钮问"内购在哪"。
