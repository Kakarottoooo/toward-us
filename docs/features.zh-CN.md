## 一、两个空间

| 空间 | 是什么 | 谁能看 |
|---|---|---|
| 只有我 | 你和 Pinky 的私人对话 | 只有你 |
| 我们俩 | 你们两个人和 Pinky 的共同对话（要邀请 TA 用自己的账号加入） | 你们俩 |

- 你在“只有我”里说的话，TA 问 Pinky 时一个字都不会透露，也不会暗示你有没有跟 Pinky 聊过；Pinky 只会说“她怎么想，只有她自己能告诉你”，再帮 TA 想怎么直接问你（2026-11-09）。
- 打开 app 默认是“只有我”：什么都可以先在这里说。说到和两个人有关的（一起的计划、两个人的回忆、共同清单、想对 TA 说的话），Pinky 会放一张卡片，比如“放进你们俩的日历”，你点确认才会进“我们俩”。
- 私人内容要你确认后，才会变成可以分享的摘要进入“我们俩”。
- 输入区一直标明是在和 Pinky 私聊，还是“我们俩”（写明 TA 也能看到）；打字、加照片或在共同对话点 @ Pinky 后仍保留。发送按钮的读屏名称也写清去向，切换空间不会把私人文字草稿带到共同输入框（2026-11-08）。
- 私下吐槽 TA 时，Pinky 先接住你的情绪，再帮你想想 TA 可能的感受，不帮写狠话、不帮“赢”；说到有危险会先顾你的安全、给求助热线，说到想伤害自己会给 988 等危机热线；严重争执反复出现、出轨或成瘾时，可以考虑咨询，但不是必须先做的事。有控制、暴力或安全恐惧时，先考虑安全和独立支持，不推荐两个人一起谈（2026-11-08）。
- Pinky 在“只有我”里替你建的提醒、日常记录、记忆，卡片上都有“撤销”，点一下就收回（不会直接删，卡片写“已撤销”）（2026-11-07）。
- 输入框上方的建议只在刚打开 app 时出现，开始打字、说话或发东西就收起，这次打开不再出现；没有按钮叫回来，想要建议就直接问 Pinky“有什么建议”（2026-11-09）。每条建议下面有一小行“为什么这样建议”，比如“纪念日还有 5 天”“你刚聊到吵架后怎么处理”（2026-11-07）。
- 不喜欢“我们俩”这个界面，可以在设置里关掉“显示“我们俩””：顶部只剩“只有我”，只影响自己的屏幕；关系、日历和共享内容都不变，随时可以再打开（2026-11-06）。
- 两个人的约定，必须两个人都同意同一份才算数。
- Pinky 起草约定只写你们已经说好的内容；“轮流做饭”还没说按每顿还是每周、谁先开始，就留在“还没定的”，不会替你们选或加上说教式条款（2026-11-08）。
- 还没配对时，在“我们俩”复制自己的邀请链接，或点“输入 TA 的邀请码”。即使两人都生成过邀请，也能直接输入对方的码加入；不用退出账号或重新注册。错误码可原地修改重试，自己的码不能提交，也可先返回私人空间。对方加入后，共同对话自动打开（2026-11-08）。
- 在“我们俩”里，Pinky 平时只在被 @ 时说话；但它问了谁一句（比如调解时“想听听 Mia 怎么看”），那个人接下来回的第一句不用 @ 也会得到回应，12 小时内有效（2026-11-07）。

## 二、“只有我”里的私人助理

| 功能 | 说明 | 可以这样说 |
|---|---|---|
| **同时在了解几个人** | 发谁的聊天截图，Pinky 就按聊天里的名字认出是谁，第一次见到就为 TA 建一份只有你看得到的档案；每个人的事分开记，不会把 Lily 的喜好套到阿杰身上。问“谁更适合我”，它先问你最看重什么，再拿聊天里的实际表现对比，说清倾向和理由，不打分、不排名，决定由你。不帮你对其中一个人编理由瞒另一个。以后和其中一人配对，对方也永远看不到其他人的档案。“只有我”顶部一排头像就是你在了解的人，点开看 Pinky 记下的 TA；第一次发某人的截图，对话里会出现“已为 X 建档 · 查看”；左上角菜单“只有我的”里有“我的 TA 们”整页（头像条的“对比”和卡片上的“完整档案”也直达）：总览看每个人到哪一步、本周谁变了、现在要你做什么；对比有一张表、Pinky 的倾向和理由、“如果今天就要决定”，以及每个人逐条对照你写下的“我想要的”；点一个人看完整档案和聊天数据（谁先开口、回复速度等）。全部自动生成，有新聊天就更新，不打分不排名，有人出现新的风险信号时菜单亮红点（2026-11-09） | Lily 和阿杰，谁更适合我？ |
| **恋爱每个阶段都能用** | “TA”是你在意的那个人：暧昧、约会、恋爱、结婚、前任都算。Pinky 从你说的话里判断阶段，从不问感情状态；能看懂 TA 的回复（如实说兴趣可能不大）、帮你回、帮你约、约会前后复盘；看到杀猪盘迹象会直接提醒；确定关系后才建议邀请 TA（11-08） | TA 回我“哈哈”，是不是对我没兴趣？ |
| **不知道怎么回 TA（核心）** | 把 TA 的话粘贴过来或发聊天截图，Pinky 看懂 TA 的意思，写一句你能直接发的回复；不用邀请 TA 也能用。新用户打开“只有我”，首页只有这一件事（11-08）。用得越多越懂 TA：你说过的、TA 在截图里透露的长期喜好和在意的事，私下记进「关于我们」，下次帮你回复时会用上；没配对也记，配对后还在，TA 永远看不到 | 她发来这段，我不想让她更失落，该怎么回？ |
| 提醒 | 一次的、每周的，到点推送 | 明天早上 8 点提醒我给妈妈打电话 |
| 心情日记 | 随口说说今天怎么样，Pinky 记在心里，只有你能看；不单独做页面，它就是 Pinky 的记忆。明确说“帮我记住”的，每一点都会分开记下；两个人和好时定下的规矩（比如“迟到提前 15 分钟说”“不当场发火”）会记成你们俩长期的约定，在“关于我们”里能看到（2026-11-07） | 今天有点累，帮我记一下 |
| 经期记录 | 记录和预测，可以在“即将到来”里看 | 那次 5 号就结束了 |
| 难开口的话 | 先私下理一理，再写成 TA 听得进去的话，你确认了才发。说清楚发生了什么、只想写道歉时，会直接给一小段日常口吻的草稿；说“别替我发”就只在私聊里写，不要求对方原谅，草稿不会自动变成约定（2026-11-08） | 我最近有点委屈，想跟 TA 说，帮我想想怎么开口 |
| 想分手时私下聊 | 不劝分、不劝和，也不默认要求先挽回或做伴侣咨询。还没想清楚时，先帮你分清自己的意愿与内疚、压力；已经决定、只要措辞时，直接给简短私人草稿。不会主动建议把犹豫分享出去；只有本人确认的文字才能进“我们俩”。私人聊天仍会留在本人会话中，不承诺“不保存”（2026-11-08，本地验证） | 我在想要不要分手，还没决定，只想先在这里理一理 |
| 情书 · 时光胶囊 | 说“帮我写封情书”，先在私聊给你完整草稿，参考你自己可见的小事和说话习惯，可以接着改；提到纪念日也不会直接安排保存。明确说想留到某天，才准备待你确认的保存卡；确认后 TA 完全不知道，到那天私下提醒你，一键用你自己的短信或邮件发给 TA。送礼物用提醒（2026-11-08，本地验证） | 帮我写封三周年情书，短一点，像我平时说话；帮我把这封信留到纪念日 |
| 喜好档案 | TA 的喜好、雷区、想要的东西，Pinky 自己记下，挑礼物时用上。生日送礼先给一个贴合心愿的建议，只用你自己可见的资料；没查过的价格和档期会说明要确认，不把预算当报价，也不替你购买、发消息或告诉 TA（2026-11-08，本地验证） | 跟你说说 TA：……；TA 下周生日，预算 300 元，送什么好？ |
| 查东西、找地方 | 餐厅、约会去处、礼物、营业时间，查好给链接；也能按预算、饮食和精力先帮你选一个在家约会的安排，需要灵感时会指向“关于我们”里的“100 件小事”（2026-11-08） | 这周六附近有什么适合约会的餐厅？ |
| 帮你订位、帮你买 | 说好哪家、哪天几点、几位，Pinky 把 OpenTable、Resy、地图、大众点评（中文）、餐厅电话和官网都准备好，日期人数已经填进去；买东西就准备好你说的店、Amazon、Google 购物比价、淘宝（中文）。你点进去，最后一步自己确认。Pinky 不替你付钱、不替你发消息、不替你打电话；缺日期、时间或人数会先问你 | 帮我订这周六晚上七点海底捞，两个人 |
| 清单和收集 | 行李清单、礼物点子、想看的电影 | 帮我列一个去日本的行李清单 |
| 照片存进回忆 | 发几张照片，说一句“存进回忆” | 把这几张照片存进回忆 |
| 导入聊天记录 | 微信、iMessage、WhatsApp，帮你看懂你们的相处方式。几年的 iMessage：有 Mac 就在 Mac 上自动同步；没有 Mac 用 Windows 电脑，把 iPhone 备份到电脑后，在 PowerShell 里照着手机输入一行短命令，选出和 TA 的对话，只读这一段（2026-11-09）。没有电脑就发最近一段的截图 | 怎么导入我们的聊天记录？ |
| 长文本聊天评理 | 在“只有我”粘贴聊天，收到导入提示后直接问“评评理”或“怎么回”，不等整份报告就根据原话回答，保留单条长消息后面的关键内容。只用本段私人对话里的原文；记录太长只读到一部分时会说明，删除原文后不再带入。提问和建议不进可共享报告（2026-11-08，本地验证） | 刚贴的微信聊天，你评评理，帮我想一句怎么回，别替我发 |
| 吵架截图帮忙 | 在“只有我”发微信或 iMessage 聊天截图，直接问“评评理”“怎么回”或“安慰我”。Pinky 读图时就回答原问题，不再等整份聊天分析完成；完整分析随后继续整理。根据原话回答，不让你重打一遍；会指出你自己做得不妥的地方，也会给一句可以复制的回复。切换到西语后，建议和回复用自然西语称呼，不夹中文的“TA”。原始提问和私人建议不会随聊天分析分享给 TA（2026-11-08） | 这是刚才的争吵，你评评理，帮我想一句怎么回 |
| 看完截图接着聊 | 在同一段私人对话里接着问“是不是我太过分”“帮我改得软一点”，Pinky 会沿用已读完的截图，不再说还在读或要求重新上传。模糊的旧承诺和时间先后会说明证据不足；删除导入原文后，不再把原文带入后续回答（2026-11-08） | 那我是不是太过分了？ |
| 安静地想 TA | 自己很累、TA 还在忙时，给一件几分钟就能独自完成的小事，例如先私下写几句想说的话；不催通话、发爱心或邀请游戏，不要求 TA 现在回复，也不会自动发送（2026-11-08） | 我只剩 15 分钟精力，想 TA 但不想打扰工作 |
| 和 Pinky 打电话 | 实时语音通话，可以私下打，也可以两个人一起 | 点右上角电话。让 Pinky 认识你（没有单独入口）：Pinky 还不太认识你时（连上 TA 之后、记下关于你的不到 5 条），点右上角电话私下打过去，它会先问你几个问题认识你——你不开心时希望怎么被对待、什么会让你难过、吵架后需要什么、你们最喜欢一起做什么、心愿、重要的人和日子；会顺着你的回答追问，哪题都能说“跳过”，有别的事想聊就直接说，它先帮你。不用你说自己是新用户：Pinky 看它记下了你多少，自己知道认不认识你。还不太认识你时，你一打开“只有我”，它就先开口问第一个问题；之后每次回复最多带一个问题，你有事它先帮你办，问题放在最后；不想答就别理它，连着两次没答它就不问了，大约问六个就结束（2026-11-08）。私下通话里你说的，挂断后 Pinky 都会记进「关于我们」，只有你能看到，想让 TA 知道哪条由你自己挑着分享（2026-11-07，借鉴 Known；创始人：“一打电话这不就是访谈了吗”） |

私人通话记下的喜好仍只属于本人：长回答末尾说的生日、心愿也会一起读；“我喜欢和 TA 做某件事”记作自己的喜好，不替 TA 认领同样的喜好。Pinky 的猜测和没有问过 TA 的事不当作事实，自己确认分享后 TA 才能看到（2026-11-08，本地修复）。

## 三、“我们俩”里的共同功能

| 功能 | 说明 |
|---|---|
| 想你了 | 点顶部的爱心，TA 那边会飘起爱心 |
| 每日一问 | 每天一个问题，先选“回答”或“暂时不答”。暂时不答会在这台设备收起这一题，刷新后仍收起，随时可重新展开；不替你提交答案，不改变 TA 的页面，也不关闭通知。开始写后仍可打字或语音回答，两个人都答了才看得到对方的答案。没提交的回答和修改会保留在当前浏览器标签页，切换空间或刷新后继续写；提交成功才清掉草稿，不提前传给 TA。关掉标签页不保证保留，不跨设备同步；浏览器不允许存储时，收起仅在这次查看有效（2026-11-08） |
| 连续一起来 | 你们俩同一天都来过（在“我们俩”说句话、答当天的问题或摸摸小家伙都算，按各自所在地的日期），就算一天；“即将到来”最上面那张“在一起”卡片下写着“🔥 连续 N 天一起来”，以及今天谁来过了：“你今天来过了”“Mia 今天来过了”“今天你们俩都来了”。只说发生了什么，不催：不写“等你”“轮到你了”，没连上的时候什么都不显示，不会出现“断了”（2026-11-07 改版） |
| 一起做决定 | 各自先私下想，Pinky 再把两边放在一起 |
| 约定 | 长期的规矩和承诺写下来，两个人都同意才算数（详见下一节）。在“只有我”里说“我想和 TA 说好……”也行：Pinky 先放一张卡片，你确认后才在“我们俩”里起草，TA 也同意了才算数（2026-11-07） |
| 计划 | 这周末、下周五吃饭这类一次性安排，跟 Pinky 说一声就直接进共同日历，前一天提醒你们俩。约会第二天你打开“只有我”时，Pinky 私下问一句“昨天和 TA 的「海底捞」怎么样？”，选择“很开心 / 还行 / 不太行”再点“发送回答”，想多说也可以直接打字；你的回答只记进你自己的「关于我们」，下次帮你们出主意时会参考，TA 看不到。点了“很开心”还可以再点“也告诉 TA”，在“我们俩”里用你的名义发一句“「海底捞」我很开心，谢谢你 ❤️”。不推送，Pinky 在“只有我”里一天最多主动问一个问题（一起看剧的“看完了吗”和纪念日不在这里问）（2026-11-07，借鉴 Known） |
| 答应过的事 | 对话里互相答应的事，Pinky 会跟进 |
| 吵架时帮一把 | 不评对错，帮你们看清刚才发生了什么。如果又是吵过的那件事，Pinky 会点出来、提起上次说好的，建议照约定来或一起写一份（2026-11-08） |
| 纪念日和重要日子 | 在一起的日子、生日、纪念日，提前提醒；“在一起第几天”计数。TA 生日前 7 天和前 1 天，Pinky 在“只有我”里私下告诉你（附上 TA 说过想要的），问要不要帮你挑礼物、订地方或写封信；过生日的那个人什么都不会收到。在一起的纪念日，你们俩各自私下收到（2026-11-08） |
| 回顾卡 | 把一段时间做成一张小故事卡 |
| 100 件小事 | 100 张卡片（“我们俩”菜单里有，“关于我们”最上面的“我们一起的”里也能点进去，显示做了几件），按户外、在家等 8 类排好，每张直接写着要做什么，做过的那张换成你们那天的照片；“今天做什么？抽一件”随机推荐；点一格可以让 Pinky 帮你们安排，做完告诉 Pinky 就存进回忆。聊到“周末干嘛”时 Pinky 也会提起它（2026-11-06 改版） |

### 约定（2026-11-06 改版）

- 等两个人点头的约定只在“我们俩”的卡片上处理（不在“即将到来”）。卡片顶部写清楚现在在等谁：“Mia 已经同意了，就差你”“你同意了，等 Mia 点头”。
- 按钮是“我同意”“我想改一下”，不再出现“第几版”“批准”这类说法。
- 安排会按日子排开，比如“周六 · 明天”“周日 · 还有 2 天”。
- “还没定的”每一条都能直接点开，打字或说话回答。Pinky 会把答案写进约定，变成新的一份，两个人再各点一次同意，“我们俩”里也会说明改了什么。
- 两个人都同意之后，Pinky 把要做的事拆出来；有日子的事会提前一天提醒，一周后来问一次进展。问进展的卡片可选择“这周做到了”“做到了一部分”“这周没做到”，再点“发送回答”；约会回访也保留三种感受供选择。没有预选答案，每张卡只有一个发送按钮，想多说也可以直接打字（2026-11-08）。
- 如果一个一次性的计划被写成了约定，卡片上可以点“这是个计划，放进日历”：每一天变成日历上的一件事，前一天提醒，这张约定卡就收起来了。

## 六、Pinky 会员（2026-11-06）

- 免费版所有功能都能用，只是每天和 Pinky 的 AI 次数少一些；用完时 Pinky 会说明天恢复，也会提一句会员。
- 会员：每天聊得更多、打电话更久，能导入更多聊天记录，小家伙的全部装扮。
- **一个人开通，两个人都是会员**。付钱的人退出关系或订阅到期，两个人都回到免费版。
- 价格：$9.99 / 月，$59.99 / 年。在“设置 → Pinky 会员”里开通。
- 在 iPhone App 里用 Apple 付款，可以“恢复购买”，在 iPhone 设置里取消；在网页上用 Stripe 付款，可以“管理或取消订阅”。
- 只认真实付款：Stripe 的签名回调或 Apple 签名的交易，App 自己说了不算。
- **内测码**：拿到内测码的情侣，在“Pinky 会员”页填进去（或者直接点邀请链接），两个人得到 90 天会员。一个码只给一对情侣用。
- **内测看板**（只有创始人能看到，在设置里）：生成邀请码、复制邀请链接；看每对情侣最近 7 天来了几个人、Pinky 帮他们做成了几件事（两个人都同意的约定、放进日历的计划、真的发出去的难开口的话、看完的剧、存下的信、记下的复盘）、操作和 AI 次数、反馈数。做成几件事和点了多少次分开算；还有这周推送了几条、点开了几次（2026-11-07）。只有次数，没有任何聊天内容。

## 七、基础

- **语音优先**：大部分事情直接说就行，打字和点按也都能用。
- **语言**：简体中文、英文、西班牙语，三种完整界面，用 `ZH / EN / ES` 切换。
- **手机**：iPhone 上可以装成 app，能收推送。
- **桌面小组件（准备中）**：给 iPhone 桌面小组件用的数据已经备好：在一起多少天、连续一起来的天数和今天谁来过、下一个重要日子。只放这些，不放聊天内容和私人内容；在 app 里登录后自动接上，退出登录就断开。小组件本身随下一版 iPhone app 上线（2026-11-06）。
- **账号**：邮箱注册、找回密码、删除账号，退出关系不需要对方批准。
- **隐私**：
  - 私人内容只有自己看得到，服务器按人分别返回各自能看的内容。
  - AI 能看到什么有明确范围。
  - 语音只在内存里处理，不保存录音。
