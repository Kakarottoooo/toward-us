# Pinky 功能清单

这是 Pinky 现在能做的所有事情，按用户看到的样子写。每次上线新功能、改掉或去掉一个功能，同一个 PR 里就更新这一页（规则写在 `AGENTS.md`）。

- 想知道“为什么这样做”：看 `docs/founder-voice.md`（创始人的原话和决定）。
- 想知道“怎么做的”：看 `docs/product-and-technology-overview.zh-CN.md`。

最后更新：2026-11-06

---

## 一、两个空间

| 空间 | 是什么 | 谁能看 |
|---|---|---|
| 只有我 | 你和 Pinky 的私人对话 | 只有你 |
| 我们俩 | 你们两个人和 Pinky 的共同对话（要邀请 TA 用自己的账号加入） | 你们俩 |

- 私人内容要你确认后，才会变成可以分享的摘要进入“我们俩”。
- 两个人的约定，必须两个人都同意同一份才算数。

## 二、“只有我”里的私人助理

| 功能 | 说明 | 可以这样说 |
|---|---|---|
| 提醒 | 一次的、每周的，到点推送 | 明天早上 8 点提醒我给妈妈打电话 |
| 心情日记 | 说两句就记下，只有你能看 | 今天有点累，帮我记一下 |
| 经期记录 | 记录和预测，可以在“即将到来”里看 | 那次 5 号就结束了 |
| 难开口的话 | 先私下理一理，再写成 TA 听得进去的话，你确认了才发 | 我最近有点委屈，想跟 TA 说，帮我想想怎么开口 |
| 情书 · 时光胶囊 | 写好封存，到那天才在“我们俩”里打开 | 帮我给 TA 写一封信，纪念日那天打开 |
| 喜好档案 | TA 的喜好、雷区、想要的东西，Pinky 自己记下，挑礼物时用上 | 跟你说说 TA：…… |
| 查东西、找地方 | 餐厅、约会去处、礼物、营业时间，查好给链接 | 这周六附近有什么适合约会的餐厅？ |
| 清单和收集 | 行李清单、礼物点子、想看的电影 | 帮我列一个去日本的行李清单 |

| 导入聊天记录 | 微信、iMessage、WhatsApp，帮你看懂你们的相处方式 | 怎么导入我们的聊天记录？ |
| 和 Pinky 打电话 | 实时语音通话，可以私下打，也可以两个人一起 | 点右上角电话 |

## 三、“我们俩”里的共同功能

| 功能 | 说明 |
|---|---|
| 想你了 | 点顶部的爱心，TA 那边会飘起爱心 |
| 每日一问 | 每天一个问题，两个人都答了才看得到对方的答案 |
| 一起做决定 | 各自先私下想，Pinky 再把两边放在一起 |
| 约定 | 长期的规矩和承诺写下来，两个人都同意才算数（详见下一节） |
| 计划 | 这周末、下周五吃饭这类一次性安排，跟 Pinky 说一声就直接进共同日历，前一天提醒你们俩 |
| 答应过的事 | 对话里互相答应的事，Pinky 会跟进 |
| 吵架时帮一把 | 不评对错，帮你们看清刚才发生了什么 |
| 纪念日和重要日子 | 在一起的日子、生日、纪念日，提前提醒；“在一起第几天”计数 |
| 回顾卡 | 把一段时间做成一张小故事卡 |
| 100 件小事 | 100 张卡片（“我们俩”菜单里就有），按户外、在家等 8 类排好，每张直接写着要做什么，做过的那张换成你们那天的照片；“今天做什么？抽一件”随机推荐；点一格可以让 Pinky 帮你们安排，做完告诉 Pinky 就存进回忆。聊到“周末干嘛”时 Pinky 也会提起它（2026-11-06 改版） |
| 那年今日 | 每年的这一天，Pinky 翻出你们以前同一天的照片和回忆 |
| 宠物小家伙 | 用照片做成你们的小宠物，有等级，每天能摸一摸，会陪你们玩游戏 |

### 约定（2026-11-06 改版）

- 卡片顶部写清楚现在在等谁：“Mia 已经同意了，就差你”“你同意了，等 Mia 点头”。
- 按钮是“我同意”“我想改一下”，不再出现“第几版”“批准”这类说法。
- 安排会按日子排开，比如“周六 · 明天”“周日 · 还有 2 天”。
- “还没定的”每一条都能直接点开，打字或说话回答。Pinky 会把答案写进约定，变成新的一份，两个人再各点一次同意，“我们俩”里也会说明改了什么。
- 两个人都同意之后，Pinky 把要做的事拆出来；有日子的事会提前一天提醒，一周后来问一次进展。
- 如果一个一次性的计划被写成了约定，卡片上可以点“这是个计划，放进日历”：每一天变成日历上的一件事，前一天提醒，这张约定卡就收起来了。

## 四、小游戏

从“我们俩”的菜单进游戏大厅，按分类挑。每个游戏都能和 TA 玩，也能和小家伙玩。

| 分类 | 游戏 | 特点 |
|---|---|---|
| 棋类 | 五子棋、象棋、黑白棋、四子棋 | 小家伙会马上回一步 |
| 画画 | 你画我猜 | 小家伙也会画、会猜 |
| 问答 | 二选一、默契问答、真心话、两个真相一个谎言 | 两个人都答完才揭晓 |
| 解谜 | 海龟汤 | Pinky 出题、当主持，可以一个人玩；提问可以语音 |
| 休闲 | 情侣飞行棋 | 双圈棋盘 + 大富翁玩法（详见下面） |
| 休闲 | 石头剪刀布 | 三局两胜，可以带赌注，Pinky 在“我们俩”里说谁要兑现 |

**情侣飞行棋（2026-11-06 改版）**
- **棋盘**：竖长方形，铺满屏幕。外圈 48 格，里面套一圈爱心内圈，四座桥把两圈连起来。
- **飞机和爱心币**：每人 2 架飞机、200 爱心币。每过一座桥 +30。
- **约会地点**：外圈有 8 个，可以买，自己的地点可以升级一次。对方停上来要付门票，也可以用一个真实的小承诺抵，Pinky 会记到“我们俩”里。
- **特殊格子**：
  - 心动卡：前进、收钱、换位置、护身符、一起拍照、回答问题等；
  - 冷静角：歇一回合，掷出 6 或者对方说句好听的话就能出来；
  - 爱心内圈：在桥头可以选择走进去，有小任务和 60 币格，但不能买地。
- **结束时**：爱心币多的人拿“今晚的小特权”，并列出这局欠下的所有小承诺。

**大厅里的通用功能**
- 每个游戏都有规则说明和战绩统计。
- 轮到你时会推送提醒（你正开着 app 时不推）。
- 没玩完的局可以“结束这局”，不算输赢。和 TA 的局结束时，“我们俩”里会说一声。
- 7 天没人动的局会收进“很久没动的”，可以一键全部结束。

## 五、可以翻看的页面

| 页面 | 里面有什么 |
|---|---|
| 即将到来 | 约定、提醒、纪念日、在一起多少天、下次见面倒计时、经期、还没拆的信、日历 |

| 设置 | 语言、通知、隐私、删除数据和账号、退出关系 |

## 六、基础

- **语音优先**：大部分事情直接说就行，打字和点按也都能用。
- **语言**：简体中文、英文、西班牙语，三种完整界面，用 `ZH / EN / ES` 切换。
- **手机**：iPhone 上可以装成 app，能收推送。
- **账号**：邮箱注册、找回密码、删除账号，退出关系不需要对方批准。
- **隐私**：
  - 私人内容只有自己看得到，服务器按人分别返回各自能看的内容。
  - AI 能看到什么有明确范围。
  - 语音只在内存里处理，不保存录音。

## 怎么维护这一页

- 上线一个用户能看到的新功能、改掉或去掉一个功能，在同一个 PR 里改这一页。
- 按用户看到的样子写：叫什么、在哪里、怎么用。不写实现细节。
- 大改版在标题后面写上日期，比如“（2026-11-06 改版）”。
- 每次更新，同时改掉顶部的“最后更新”日期。
