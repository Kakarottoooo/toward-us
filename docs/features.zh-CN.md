# Pinky 功能清单

这是 Pinky 现在能做的所有事情，按用户看到的样子写。每次上线新功能、改掉或去掉一个功能，同一个 PR 里就更新这一页（规则写在 `AGENTS.md`）。

- 想知道“为什么这样做”：看 `docs/founder-voice.md`（创始人的原话和决定）。
- 想知道“怎么做的”：看 `docs/product-and-technology-overview.zh-CN.md`。

最后更新：2026-11-08（省时间改版、争吵截图求助与追问、每日一问草稿与新用户按钮）

## 一、两个空间

| 空间 | 是什么 | 谁能看 |
|---|---|---|
| 只有我 | 你和 Pinky 的私人对话 | 只有你 |
| 我们俩 | 你们两个人和 Pinky 的共同对话（要邀请 TA 用自己的账号加入） | 你们俩 |

- 打开 app 默认是“只有我”：什么都可以先在这里说。说到和两个人有关的（一起的计划、两个人的回忆、共同清单、想对 TA 说的话），Pinky 会放一张卡片，比如“放进你们俩的日历”，你点确认才会进“我们俩”。
- 私人内容要你确认后，才会变成可以分享的摘要进入“我们俩”。
- 私下吐槽 TA 时，Pinky 先接住你的情绪，再帮你想想 TA 可能的感受，不帮写狠话、不帮“赢”；说到有危险会先顾你的安全、给求助热线，说到想伤害自己会给 988 等危机热线；同一件严重的事反复吵、说到分手出轨成瘾时，会建议找伴侣咨询师（2026-11-08）。
- Pinky 在“只有我”里替你建的提醒、日常记录、记忆，卡片上都有“撤销”，点一下就收回（不会直接删，卡片写“已撤销”）（2026-11-07）。
- 输入框上方的建议，每条下面有一小行“为什么这样建议”，比如“纪念日还有 5 天”“你刚聊到吵架后怎么处理”（2026-11-07）。
- 不喜欢“我们俩”这个界面，可以在设置里关掉“显示“我们俩””：顶部只剩“只有我”，只影响自己的屏幕；关系、日历和共享内容都不变，随时可以再打开（2026-11-06）。
- 两个人的约定，必须两个人都同意同一份才算数。
- 在“我们俩”里，Pinky 平时只在被 @ 时说话；但它问了谁一句（比如调解时“想听听 Mia 怎么看”），那个人接下来回的第一句不用 @ 也会得到回应，12 小时内有效（2026-11-07）。

## 二、“只有我”里的私人助理

| 功能 | 说明 | 可以这样说 |
|---|---|---|
| 提醒 | 一次的、每周的，到点推送 | 明天早上 8 点提醒我给妈妈打电话 |
| 心情日记 | 随口说说今天怎么样，Pinky 记在心里，只有你能看；不单独做页面，它就是 Pinky 的记忆。明确说“帮我记住”的，每一点都会分开记下；两个人和好时定下的规矩（比如“迟到提前 15 分钟说”“不当场发火”）会记成你们俩长期的约定，在“关于我们”里能看到（2026-11-07） | 今天有点累，帮我记一下 |
| 经期记录 | 记录和预测，可以在“即将到来”里看 | 那次 5 号就结束了 |
| 难开口的话 | 先私下理一理，再写成 TA 听得进去的话，你确认了才发 | 我最近有点委屈，想跟 TA 说，帮我想想怎么开口 |
| 情书 · 时光胶囊 | Pinky 帮你写好先存着，TA 完全不知道；到那天私下提醒你，一键用你自己的短信或邮件发给 TA（不从 Pinky 发出去）。送礼物用提醒 | 帮我给 TA 写一封信，纪念日那天发给 TA |
| 喜好档案 | TA 的喜好、雷区、想要的东西，Pinky 自己记下，挑礼物时用上 | 跟你说说 TA：…… |
| 查东西、找地方 | 餐厅、约会去处、礼物、营业时间，查好给链接 | 这周六附近有什么适合约会的餐厅？ |
| 帮你订位、帮你买 | 说好哪家、哪天几点、几位，Pinky 把 OpenTable、Resy、地图、大众点评（中文）、餐厅电话和官网都准备好，日期人数已经填进去；买东西就准备好你说的店、Amazon、Google 购物比价、淘宝（中文）。你点进去，最后一步自己确认。Pinky 不替你付钱、不替你发消息、不替你打电话；缺日期、时间或人数会先问你 | 帮我订这周六晚上七点海底捞，两个人 |
| 清单和收集 | 行李清单、礼物点子、想看的电影 | 帮我列一个去日本的行李清单 |
| 照片存进回忆 | 发几张照片，说一句“存进回忆” | 把这几张照片存进回忆 |
| 导入聊天记录 | 微信、iMessage、WhatsApp，帮你看懂你们的相处方式 | 怎么导入我们的聊天记录？ |
| 吵架截图帮忙 | 在“只有我”发微信或 iMessage 聊天截图，直接问“评评理”“怎么回”或“安慰我”。Pinky 先读截图，再根据原话回答，不让你重打一遍；会指出你自己做得不妥的地方，也会给一句可以复制的回复。切换到西语后，建议和回复用自然西语称呼，不夹中文的“TA”。原始提问和私人建议不会随聊天分析分享给 TA（2026-11-08） | 这是刚才的争吵，你评评理，帮我想一句怎么回 |
| 看完截图接着聊 | 在同一段私人对话里接着问“是不是我太过分”“帮我改得软一点”，Pinky 会沿用已读完的截图，不再说还在读或要求重新上传。模糊的旧承诺和时间先后会说明证据不足；删除导入原文后，不再把原文带入后续回答（2026-11-08） | 那我是不是太过分了？ |
| 和 Pinky 打电话 | 实时语音通话，可以私下打，也可以两个人一起 | 点右上角电话。让 Pinky 认识你（没有单独入口）：Pinky 还不太认识你时（连上 TA 之后、记下关于你的不到 5 条），点右上角电话私下打过去，它会先问你几个问题认识你——你不开心时希望怎么被对待、什么会让你难过、吵架后需要什么、你们最喜欢一起做什么、心愿、重要的人和日子；会顺着你的回答追问，哪题都能说“跳过”，有别的事想聊就直接说，它先帮你。不用你说自己是新用户：Pinky 看它记下了你多少，自己知道认不认识你。还不太认识你时，你一打开“只有我”，它就先开口问第一个问题；之后每次回复最多带一个问题，你有事它先帮你办，问题放在最后；不想答就别理它，连着两次没答它就不问了，大约问六个就结束（2026-11-08）。私下通话里你说的，挂断后 Pinky 都会记进「关于我们」，只有你能看到，想让 TA 知道哪条由你自己挑着分享（2026-11-07，借鉴 Known；创始人：“一打电话这不就是访谈了吗”） |

## 三、“我们俩”里的共同功能

| 功能 | 说明 |
|---|---|
| 想你了 | 点顶部的爱心，TA 那边会飘起爱心 |
| 每日一问 | 每天一个问题，两个人都答了才看得到对方的答案。没提交的回答和修改会保留在当前浏览器标签页，切换空间或刷新后继续写；提交成功才清掉草稿，不提前传给 TA。关掉标签页不保证保留，不跨设备同步（2026-11-08） |
| 连续一起来 | 你们俩同一天都来过（在“我们俩”说句话、答当天的问题或摸摸小家伙都算，按各自所在地的日期），就算一天；“即将到来”最上面那张“在一起”卡片下写着“🔥 连续 N 天一起来”，以及今天谁来过了：“你今天来过了”“Mia 今天来过了”“今天你们俩都来了”。只说发生了什么，不催：不写“等你”“轮到你了”，没连上的时候什么都不显示，不会出现“断了”（2026-11-07 改版） |
| 一起做决定 | 各自先私下想，Pinky 再把两边放在一起 |
| 约定 | 长期的规矩和承诺写下来，两个人都同意才算数（详见下一节）。在“只有我”里说“我想和 TA 说好……”也行：Pinky 先放一张卡片，你确认后才在“我们俩”里起草，TA 也同意了才算数（2026-11-07） |
| 计划 | 这周末、下周五吃饭这类一次性安排，跟 Pinky 说一声就直接进共同日历，前一天提醒你们俩。约会第二天你打开“只有我”时，Pinky 私下问一句“昨天和 TA 的「海底捞」怎么样？”，点“很开心 / 还行 / 不太行”就是回答，想多说也可以直接打字；你的回答只记进你自己的「关于我们」，下次帮你们出主意时会参考，TA 看不到。点了“很开心”还可以再点“也告诉 TA”，在“我们俩”里用你的名义发一句“「海底捞」我很开心，谢谢你 ❤️”。不推送，Pinky 在“只有我”里一天最多主动问一个问题（一起看剧的“看完了吗”和纪念日不在这里问）（2026-11-07，借鉴 Known） |
| 答应过的事 | 对话里互相答应的事，Pinky 会跟进 |
| 吵架时帮一把 | 不评对错，帮你们看清刚才发生了什么。如果又是吵过的那件事，Pinky 会点出来、提起上次说好的，建议照约定来或一起写一份（2026-11-08） |
| 纪念日和重要日子 | 在一起的日子、生日、纪念日，提前提醒；“在一起第几天”计数。TA 生日前 7 天和前 1 天，Pinky 在“只有我”里私下告诉你（附上 TA 说过想要的），问要不要帮你挑礼物、订地方或写封信；过生日的那个人什么都不会收到。在一起的纪念日，你们俩各自私下收到（2026-11-08） |
| 回顾卡 | 把一段时间做成一张小故事卡 |
| 100 件小事 | 100 张卡片（“我们俩”菜单里有，“关于我们”最上面的“我们一起的”里也能点进去，显示做了几件），按户外、在家等 8 类排好，每张直接写着要做什么，做过的那张换成你们那天的照片；“今天做什么？抽一件”随机推荐；点一格可以让 Pinky 帮你们安排，做完告诉 Pinky 就存进回忆。聊到“周末干嘛”时 Pinky 也会提起它（2026-11-06 改版） |
| 一起看过的 | 你们一起看过、在追、想一起看的剧和电影（2026-11-07）。说一句“我们昨晚看完了《沙丘2》”，Pinky 就记下片名、哪天、一起看还是各自在两个城市看、看到第几集、你们的一句感想；在“只有我”里说的，要你点确认才放上去。约好“周六晚上 8 点一起看第 13 集”，Pinky 放进共同日历，异地的话写上两边各自的时间，当天提醒；第二天上午在“我们俩”里问一句“看完了吗？”，点“看完了”就记上，点“还没”就留着下次。在“关于我们”最上面的“我们一起的”里点“一起看过的”就能看到整面墙（先是文字卡片，没有海报）。导入过聊天记录的话，分析里会列出你们以前一起看过的，点“放进一起看过的”交给 Pinky。Pinky 看不到你们在爱奇艺、Netflix 等平台上看了什么，只记你们告诉它的 |
| 那年今日 | 每年的这一天，Pinky 翻出你们以前同一天的照片和回忆 |
| 宠物小家伙 | 用照片做成你们的小宠物，有等级，可以摸一摸，会陪你们玩游戏。它不会说“想你们了”，也不会提醒谁今天还没来（2026-11-07）。在它的小窝里可以换装扮（蝴蝶结、小皇冠、红围巾、圆眼镜、小花、圣诞帽）：会员全部能穿，不是会员也可以单买一件 $1.99，一个人买了两个人都能用；给它穿上，两个人看到的都会变 |

### 约定（2026-11-06 改版）

- 等两个人点头的约定只在“我们俩”的卡片上处理（不在“即将到来”）。卡片顶部写清楚现在在等谁：“Mia 已经同意了，就差你”“你同意了，等 Mia 点头”。
- 按钮是“我同意”“我想改一下”，不再出现“第几版”“批准”这类说法。
- 安排会按日子排开，比如“周六 · 明天”“周日 · 还有 2 天”。
- “还没定的”每一条都能直接点开，打字或说话回答。Pinky 会把答案写进约定，变成新的一份，两个人再各点一次同意，“我们俩”里也会说明改了什么。
- 两个人都同意之后，Pinky 把要做的事拆出来；有日子的事会提前一天提醒，一周后来问一次进展。问进展的卡片上有“这周做到了”“做到了一部分”“这周没做到”三个按钮，点一下就是回答，想多说也可以直接打字（2026-11-07）。
- 如果一个一次性的计划被写成了约定，卡片上可以点“这是个计划，放进日历”：每一天变成日历上的一件事，前一天提醒，这张约定卡就收起来了。

## 四、小游戏

从“我们俩”的菜单进游戏大厅，按分类挑。每个游戏都能和 TA 玩，也能和小家伙玩。

| 分类 | 游戏 | 特点 |
|---|---|---|
| 棋类 | 五子棋、象棋、黑白棋、四子棋 | 小家伙会马上回一步 |
| 画画 | 你画我猜 | 小家伙也会画、会猜 |
| 问答 | 二选一、默契问答、真心话、两个真相一个谎言 | 两个人都答完才揭晓 |
| 解谜 | 海龟汤 | Pinky 出题、当主持，可以一个人玩；提问可以语音 |
| 休闲 | 情侣飞行棋 | 双圈棋盘 + 大富翁玩法（详见下面） |
| 休闲 | 石头剪刀布 | 三局两胜，可以带赌注，Pinky 在“我们俩”里说谁要兑现 |

**情侣飞行棋（2026-11-06 改版）**
- **棋盘**：竖长方形，铺满屏幕。外圈 48 格，里面套一圈爱心内圈，四座桥把两圈连起来。
- **飞机和爱心币**：每人 2 架飞机、200 爱心币。每过一座桥 +30。
- **约会地点**：外圈有 8 个，可以买，自己的地点可以升级一次。对方停上来要付门票，也可以用一个真实的小承诺抵，Pinky 会记到“我们俩”里。
- **特殊格子**：
  - 心动卡：前进、收钱、换位置、护身符、一起拍照、回答问题等；
  - 冷静角：歇一回合，掷出 6 或者对方说句好听的话就能出来；
  - 爱心内圈：在桥头可以选择走进去，有小任务和 60 币格，但不能买地。
- **结束时**：爱心币多的人拿“今晚的小特权”，并列出这局欠下的所有小承诺。

**大厅里的通用功能**
- 每个游戏都有规则说明和战绩统计。
- 轮到你时会推送提醒（你正开着 app 时不推）。
- 没玩完的局可以“结束这局”，不算输赢。和 TA 的局结束时，“我们俩”里会说一声。
- 7 天没人动的局会收进“很久没动的”，可以一键全部结束。

**通知（2026-11-07 省时间改版）**
- Pinky 只在需要你的时候找你：TA 说的话、你设的提醒、Pinky 问你们的事（每日一问、看完了吗、约定做到了吗）。Pinky 问的事，推送里直接写着问什么，不用先打开 app 才知道。
- 回顾卡、那年今日、小家伙长大这些“惊喜”默认不推送，打开“我们俩”时就能看到；想要的人可以在“设置 → 通知 → Pinky 的惊喜”里打开。
- 只是 Pinky 自己发起的推送，每人每天最多 3 条；TA 说的话和你设的提醒不算在内。
- 夜间免打扰（22:00–8:00，按你所在地的时间）默认打开，晚上只推你自己设的提醒；知道你在哪个时区才生效，可以关掉。
- 自己设提醒不用再填时区，手机知道你在哪。

## 六、Pinky 会员（2026-11-06）

- 免费版所有功能都能用，只是每天和 Pinky 的 AI 次数少一些；用完时 Pinky 会说明天恢复，也会提一句会员。
- 会员：每天聊得更多、打电话更久，能导入更多聊天记录，小家伙的全部装扮。
- **一个人开通，两个人都是会员**。付钱的人退出关系或订阅到期，两个人都回到免费版。
- 价格：$9.99 / 月，$59.99 / 年。在“设置 → Pinky 会员”里开通。
- 在 iPhone App 里用 Apple 付款，可以“恢复购买”，在 iPhone 设置里取消；在网页上用 Stripe 付款，可以“管理或取消订阅”。
- 只认真实付款：Stripe 的签名回调或 Apple 签名的交易，App 自己说了不算。
- **内测码**：拿到内测码的情侣，在“Pinky 会员”页填进去（或者直接点邀请链接），两个人得到 90 天会员。一个码只给一对情侣用。
- **内测看板**（只有创始人能看到，在设置里）：生成邀请码、复制邀请链接；看每对情侣最近 7 天来了几个人、Pinky 帮他们做成了几件事（两个人都同意的约定、放进日历的计划、真的发出去的难开口的话、看完的剧、存下的信、记下的复盘）、操作和 AI 次数、反馈数。做成几件事和点了多少次分开算；还有这周推送了几条、点开了几次（2026-11-07）。只有次数，没有任何聊天内容。

## 七、基础

- **语音优先**：大部分事情直接说就行，打字和点按也都能用。
- **语言**：简体中文、英文、西班牙语，三种完整界面，用 `ZH / EN / ES` 切换。
- **手机**：iPhone 上可以装成 app，能收推送。
- **桌面小组件（准备中）**：给 iPhone 桌面小组件用的数据已经备好：在一起多少天、连续一起来的天数和今天谁来过、下一个重要日子。只放这些，不放聊天内容和私人内容；在 app 里登录后自动接上，退出登录就断开。小组件本身随下一版 iPhone app 上线（2026-11-06）。
- **账号**：邮箱注册、找回密码、删除账号，退出关系不需要对方批准。
- **隐私**：
  - 私人内容只有自己看得到，服务器按人分别返回各自能看的内容。
  - AI 能看到什么有明确范围。
  - 语音只在内存里处理，不保存录音。
