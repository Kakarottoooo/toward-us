# Pinky AI native 重设计

日期：2026-11-02。依据：创始人当晚的决定（已记进 `docs/founder-voice.md`）。只做手机版。

## 为什么改

现在的 App 是两个产品叠在一起：对话首页有一个输入框，"全部功能"里的共同空间首页又有一个，私人空间、计划页、决定页里还各有自己的 Agent 输入框和语音助手；沟通、决定、计划、回忆是一排传统功能页。用户不知道该在哪儿说话。

## 一句话

**只有两个对话——"只有我"和"我们俩"——Pinky 在对话里办所有事；左侧抽屉只用来翻看办完的结果。**

## 目标

- 第一批 5–10 对情侣反复用这四件事，四件都是核心：难开口的话、说到做到（约定）、吵架时调解、日常记事与回忆。
- 四件事都在对话里开始、在对话里完成；不需要看的功能没有入口。
- 需要看的东西（约定、日程与提醒、回忆、清单）在抽屉里，页面只看和做小改动（勾选、删除、改日期），不放新的输入框；想新增就点"跟 Pinky 说"回到对话。

## 不做

- 不加底部标签栏，不保留"共同空间首页"，不做电脑版。
- 页面里不再出现第二个对话框或语音助手。
- Pinky 在"只有我"里只在用户设好的提醒时主动开口；在"我们俩"里只在被叫到或有正事（待批准约定、提醒、复盘、转达已确认的话）时开口。

## 不能破坏的规则（沿用）

私人内容只有本人能看；分享前本人先看到将发出的那一版并确认；约定双方批准同一版本；每个长期对象保留来源、可见范围和服务端按人投影，不靠前端隐藏。三种界面语言完整。

## 现有功能怎么处理

| 现有 | 处理 |
|---|---|
| 只有我 / 我们俩对话、难开口的话、轻量约定 | 留，是骨架 |
| 计划草稿、纪念日、提醒、记心情、记回忆 | 在对话里说（私人 Agent 已能建这些），抽屉里看 |
| 清单 | 私人 Agent 新增"清单项"能力；抽屉里看和勾选 |
| 正式共同决定 | 并进对话（见第 3 步） |
| 调解房间 | 并进"我们俩"的语音模式（见第 4 步），面对面一台手机和各用各的手机两种都要 |
| 共同空间首页、私人空间页、通知中心页、页面里的语音助手和 Agent 输入框 | 删。通知改为对话里的消息加系统推送 |
| 隐私与账号、语言 | 留，在抽屉底部"设置"里 |
| iMessage 入口 | 留，规则同 App |

## 抽屉

左上角按钮拉出，盖在对话上，点外面或往左滑关闭。打开前先收起键盘、停掉语音。

- 顶部：PINKY 和自己的名字。
- **我们俩的**：约定、日程与提醒、回忆、清单。还没配对时这一组只显示"邀请 TA 一起来"，回忆、日程等挪到"只有我的"里显示自己的。
- **只有我的**：我的提醒、私人回忆（只有自己能看）。
- 底部：设置（隐私、账号、语言）、退出登录。

每个页面顶上只有"← 返回对话"和标题，没有导航栏。

## 分步做（每步单独提交，做完自查再做下一步）

1. **外壳**：做抽屉；删共同空间首页、导航栏、私人空间页、各页面的语音助手和多余输入框、"回到对话"浮动按钮；各页面换成"返回对话 + 标题"的头部；调解/复盘相关页的返回都回到对话。
2. **只看的页面**：约定（待批准 / 进行中 / 历史）、日程与提醒（纪念日和提醒合成一条时间线）、回忆（心情和回忆一条时间线）、清单。去掉新建表单，保留勾选、删除、改日期；页面底部"跟 Pinky 说"带着一句开头回到对话。私人 Agent 增加清单项。
3. **正式决定并进对话**：在"我们俩"里叫 Pinky "帮我们决定 X" → Pinky 在两人各自的"只有我"里私下问观点（各自只看到自己的）→ 两人都答完，Pinky 在"我们俩"发共同分析和约定草稿 → 双方批准同一版本 → 到期在"我们俩"提醒复盘，复盘也在对话里谈。复用现有的议题、观点、分析、承诺和复盘对象。
4. **调解并进"我们俩"**：输入框旁加"一起说"。面对面：一台手机，每段开口前选是谁在说（沿用现有的按人归属）；异地：各自在自己手机上说。说的内容进"我们俩"；结束后 Pinky 在各自"只有我"里给私下反馈，在"我们俩"给共同分析，需要时直接起草约定。复用现有调解分析。
5. **照片回忆**：对话里可以发照片。在"只有我"发的照片默认私人，要分享时照常先确认；在"我们俩"发的两人都能看。Pinky 把照片存成回忆，回忆页显示照片。本地内测时照片存在数据文件旁边的文件夹里，通过登录后的接口按人取。

## 留给实现时自己定的（我的判断）

- 抽屉宽度、动画、图标；页面的具体排版沿用现有红蓝和控件样式。
- 时间线里的分组方式（按月）。
- 删除的旧页面代码直接删，不留开关。

## 还没定、不影响今晚开工的

- iMessage 里发照片是否存进回忆。
